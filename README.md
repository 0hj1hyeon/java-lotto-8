# java-lotto-precourse
1. 구입금액 구현
 - 구입금액 입력 구현
 - 구입한 금액 자료형 유효성 검사 구현

2. 구입한 로또 구현
- 구입한 금액 1000원 단위인지 확인 구현
- 구입한 금액 0이상인지 확인 구현
- 구입한 로또 생성 로직 구현
- 로또 생성 번호 출력 구현

3. 당첨 번호 구현
- 당첨 번호 및 보너스 번호 입력 구현
- 당첨 번호 6개인지 확인 검사 구현
- 번호가 1에서 45 사이인지 확인 구현
- 번호 자료형이 맞는지 확인 구현
- 보너스 번호 1개인지 확인 검사 구현
- 당첨 번호 및 보너스 번호 중복 확인 후 검사 구현

4. 당첨 통계 계산 구현
- 3,4,5,6개 일치 계산 구현
- 수익률 계산 구현
- 당첨 통계 출력 구현
