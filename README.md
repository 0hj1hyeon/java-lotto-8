# java-lotto-precourse
1. 입출력 구현
 - 구입금액 입력 구현
 - 구입한 로또 개수 및 번호 출력 구현
 - 당첨 번호 및 보너스 번호 입력 구현
 - 당첨 통계 출력 구현

2. 구입한 로또 구현
- 구입한 로또 생성 로직 구현
- 구입한 금액 숫자 맞는지 유효성 검사 구현
- 구입한 금액 1000원 단위인지 확인 구현

3. 당첨 번호 입력 유효성 검사 구현
- 당첨 번호 6개 확인 검사 구현
- 보너스 번호 1개인지 확인 검사 구현
- 당첨 번호 및 보너스 번호 중복 확인 후 검사 구현

4. 당첨 통계 계산 구현
- 3,4,5,6개 일치 계산 구현
- 수익률 계산 구현
